# 撲克弱點特訓

三天的 NLHE（無限注德州）練習站。場景是 6-max 現金局、100BB，每天約 30 分鐘。送出後立刻看講解。

請開啟 [index.html](index.html)，或等這個分支合併後造訪 GitHub Pages：

https://affordtolose-collab.github.io/poker-training/

## 紀錄

每一題會在這台瀏覽器留下不可覆寫的一筆：題目快照、你選的答案、正確選項、講解、對錯、弱點標籤、場次、第幾次作答，以及決策時間。時間從題目出現算到第一次送出；暫停、切換分頁、回到別頁、閱讀講解都不計。重新整理不會把頁面關掉的那段時間算進去。

舊版只在 `localStorage` 的 `pkt` 存了對或錯。那些筆會保留，選項和時間標成未知，不會回推一個假時間。

雲端同步**還沒有連接**。GitHub Pages 不能替你寫入私人資料庫。要把紀錄交給助教，請在「匯出」下載 JSON，私下傳送。不要把紀錄、權杖或密碼放進這個公開倉庫。接上私人後端之前要做的決定，寫在 [docs/sync.md](docs/sync.md)。

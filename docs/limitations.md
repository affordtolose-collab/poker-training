# 這一版做不到的事

- 自動私人同步沒有後端，所以沒有連接，也沒有測試過上傳。介面不會假裝已經同步。
- 舊版 `pkt` 只有每個題號的對或錯。選項、講解快照、時間和作答次數都標成未知。
- 硬體當機或分頁被系統殺掉時，最多可能少計最後 5 秒的自動存檔間隔。關掉的那段時間不會被加進去，也不會編造。
- CSV 沒有題目快照。完整備份用 JSON。同一編號內容不同時拒絕匯入。
- 決策偏慢使用這位使用者自己的中位數。樣本少於 4 筆時不標成偏慢，答對但偏慢也不算弱點。
- 題目第 3 天最後一題的舊牌面只有兩張黑桃，和「第三張黑桃」矛盾。題庫改成 K♠ J♠ 9♠，點數不變。舊紀錄沒有牌面快照，所以不會被說成是在新牌面上答對或答錯。
- 這一版只放在分支上，沒有合併，也沒有重新發布 GitHub Pages。
